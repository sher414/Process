# 🧪 LABS — Laboratorios de práctica en n8n

Flujos de trabajo construidos paso a paso con fines de aprendizaje y experimentación. A diferencia de la carpeta `Automatizaciones` (proyectos aplicados), aquí el foco está en el **proceso de construcción** y la práctica de conceptos.

---

## 📋 Laboratorios

### LAB 01 — Flujo de Leads
Construcción de un pipeline de captación y gestión de leads: captura de datos desde un formulario, procesamiento y registro automático. Practica la conexión entre disparadores, transformación de datos y destinos (hojas de cálculo, notificaciones).

### LAB 02 — Workflow Productivo
Laboratorio orientado a un flujo de productividad: automatización de tareas recurrentes y orquestación de acciones para optimizar el trabajo diario.

---

## 🚀 Cómo usar estos laboratorios

Los archivos son workflows de n8n. Para importarlos:
1. Abrí n8n → **Workflows → Import from File**
2. Seleccioná el archivo del laboratorio
3. Configurá tus credenciales en los nodos que lo requieran
4. Ejecutá paso a paso para ver cómo fluyen los datos

> 💡 Estos labs están pensados para aprender: revisá cada nodo y experimentá modificándolos.
